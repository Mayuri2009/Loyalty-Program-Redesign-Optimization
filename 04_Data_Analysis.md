# Data Analysis & Root Cause Validation

## 1. Objective

The objective of this analysis is to validate the issues
identified during the AS-IS analysis using loyalty program data.

## 2. Dataset

The analysis uses simulated loyalty program data representing
10,000 loyalty members.

## 3. Key Metrics

| Metric | Result |
|---|---:|
| Total Loyalty Members | 10,000 |
| Active Members | 3,600 |
| Inactive Members | 6,400 |
| Members Who Redeemed Rewards | 2,100 |
| Repeat Purchasers | 4,200 |
| Average Member Spend | $420 |
| Average Active Member Spend | $560 |
| Average Inactive Member Spend | $340 |

## 4. Key Calculations

### Active Member Rate

Active Members / Total Members × 100 = 36%

### Inactive Member Rate

Inactive Members / Total Members × 100 = 64%

### Redemption Rate

Members Who Redeemed / Total Members × 100 = 21%

## 5. Findings

- Loyalty program active participation is 36%.
- 64% of members are inactive.
- Reward redemption is 21%.
- Active members have a higher average spend than inactive members.
- The data indicates an opportunity to improve engagement and repeat purchasing.

## 6. Data Limitations

The data is simulated for portfolio purposes.
The analysis does not establish that the loyalty program
causes higher spending.

Customer research is required to understand the reasons
behind low engagement and reward redemption.

## 7. Validated Business Problem

The loyalty program has low active participation and
low reward redemption, creating an opportunity to improve
customer engagement, repeat purchases and measurable
business value.
