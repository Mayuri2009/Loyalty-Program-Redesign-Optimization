# Loyalty Program Redesign & Optimization

## 📌 Project Overview

This project demonstrates a Business Analysis approach to
redesigning a retail loyalty program with the objective of
improving customer engagement, reward redemption and
repeat purchases.

The project follows a simplified end-to-end BA lifecycle
from business problem identification through requirements,
process analysis, UAT and KPI definition.

---

## 🎯 Business Problem

The existing loyalty program has a large enrolled customer
base, but customer engagement and reward redemption are low.

The business wants to improve customer engagement, provide
more relevant rewards and simplify the redemption experience.

---

## 🎯 Project Objectives

- Increase loyalty-member engagement
- Improve repeat purchases
- Provide more relevant rewards
- Simplify reward redemption
- Improve measurement of loyalty program performance

## 📊 Key Findings

- Active loyalty member rate: 36%
- Inactive member rate: 64%
- Reward redemption rate: 21%
- Repeat purchase rate: 42%
- Active members showed higher average spend than inactive members.

The figures are simulated for portfolio purposes.

---

## 💡 Proposed Solution

The redesigned loyalty program focuses on:

- Clear points balance visibility
- Relevant customer rewards
- Simplified reward redemption
- Better repeat-purchase engagement
- KPI-based performance monitoring
